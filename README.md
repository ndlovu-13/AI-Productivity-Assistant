⚙️ Technical Requirements & Prompt Engineering

To guarantee predictable, highly professional, and structured responses from the underlying language models (such as gemini-2.5-flash-preview-09-2025), the application implements Structured Prompt Engineering principles:

Prompt Strategies:
  Email Generation:
    System Prompt: "Act as an elite executive assistant. Draft highly polished emails adjusting tone strictly according to parameters. Keep outputs directly copy-pasteable without placeholder brackets unless absolutely necessary."
  Meeting Summarization:
    System Prompt: "Parse input text. Extract: 1. Executive Summary, 2. Key Points, 3. Action Items (assigned), 4. Deadlines. Format strictly using markdown headings and bullet points."
  Task Planning:
    System Prompt: "Evaluate tasks using the Eisenhower Matrix. Output a prioritized daily schedule sorted by priority ranking, adding duration estimates."
  Research Assistant:
    System Prompt: "Provide an objective, structured deep-dive on the topic. Breakdown into Summary, Current Trends, Critical Risks, and Key Actions."


Key Implementation Guardrails

Loading State UX: Buttons and panels switch to a disabled loading status during pending API responses to prevent concurrent form submissions.

Robust Fallbacks & Retries: Implements an exponential backoff loop for API network failures, retrying up to 5 times before failing gracefully with user-friendly custom error modals.

Browser-Safe APIs: Avoids obstructive browser alert() elements, defaulting instead to immersive in-app notifications and toast components.

🛠️ Getting Started

Prerequisites

A modern web browser (Chrome, Firefox, Safari, Edge).

An internet connection to fetch Tailwind CSS styles, icons, and connect to the Gemini API services.

Installation & Run instructions

Clone this repository to your local system:

git clone [https://github.com/your-username/ai-workplace-productivity-assistant.git](https://github.com/your-username/ai-workplace-productivity-assistant.git)


Navigate to the project directory:

cd ai-workplace-productivity-assistant


Since this application is packaged as a single-file web application, you can open the main entry file (index.html or App.jsx) directly in your browser, or spin up a simple static development server:

# Using Python 3 to serve the application locally
python3 -m http.server 8000


Open http://localhost:8000 in your web browser.
